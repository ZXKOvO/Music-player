# 基于 Qt + QML + FFmpeg + SDL2 的音乐播放器开发文档

## 一、技术选型

| 模块 | 技术方案 | 说明 |
|------|----------|------|
| UI 框架 | Qt6 + QML | 声明式 UI，界面与逻辑分离 |
| 音频解码 | FFmpeg (libavformat, libavcodec, libswresample) | 支持 mp3/flac/wav/aac/ogg 等主流格式 |
| 音频输出 | SDL2 | 跨平台音频播放，低延迟 |
| 构建工具 | CMake | 管理 qmake 和第三方库链接 |
| C++ 后端 | Qt C++ 类 | 通过 QObject 暴露给 QML 调用 |


## 二、整体架构

分为三层：

1. **QML UI 层**：Main.qml、Playlist.qml、PlayerControls.qml，负责界面展示与用户交互
2. **C++ Backend 层**：PlayerController 作为桥梁暴露给 QML，内部组合 AudioDecoder 和 SDLAudioOutput
3. **音频处理层**：FFmpeg 解码音频文件为 PCM 裸数据，SDL2 负责将 PCM 数据输出到扬声器

数据流向：音频文件 → FFmpeg 解码 → PCM 数据 → SDL2 音频设备 → 扬声器

---

## 三、模块职责

### 3.1 AudioDecoder（音频解码器）

- 打开音频文件并解析格式信息
- 使用 FFmpeg 解封装、解码音频流
- 使用 Swresample 将音频统一重采样为固定格式（如 44100Hz / 双声道 / float32）
- 提供 PCM 数据读取接口供下游消费
- 支持 seek 到指定时间位置

核心 API：打开文件、关闭文件、读取 PCM 数据、seek、获取时长与当前播放位置、获取音频格式信息。

### 3.2 SDLAudioOutput（音频输出）

- 初始化 SDL 音频子系统，打开音频设备
- 通过 SDL 回调机制从解码器获取 PCM 数据
- 控制播放、暂停、停止
- 支持音量调节（回调中对 PCM 采样值乘系数）
- 可选：变速播放

### 3.3 PlayerController（播放控制器）

- 注册为 QML 类型，暴露属性和方法给 QML 调用
- 封装 AudioDecoder 和 SDLAudioOutput 的协作逻辑
- 通过 Q_PROPERTY 暴露 playing、duration、position、volume 等状态
- 通过 QTimer 定时轮询播放进度，发射 positionChanged 信号
- 处理异常并通过 errorOccurred 信号通知 QML

### 3.4 环形缓冲区（RingBuffer）

- 线程安全的数据结构，用于桥接解码线程与 SDL 音频回调线程
- 解码器作为生产者向缓冲区写入 PCM 数据
- SDL 回调作为消费者从缓冲区读取 PCM 数据
- 缓冲区容量建议 1~2 秒 PCM 数据量

---

## 四、音频数据处理流程

```
音频文件 → FFmpeg 解封装 → FFmpeg 解码 → Swresample 重采样
    → 环形缓冲区 → SDL2 音频设备回调 → 扬声器
```

各步骤说明：

1. **解封装**：读取容器格式，提取音频编码包（packet）
2. **解码**：将编码包解码为原始音频帧（frame）
3. **重采样**：将解码后的音频转换为统一目标格式（采样率、声道数、样本格式）
4. **缓冲**：PCM 数据写入线程安全的环形缓冲区
5. **输出**：SDL2 在音频线程中通过回调函数从缓冲区取出数据并播放

---

## 五、线程模型

- **主线程**（Qt 事件循环）：运行 QML UI、PlayerController 状态更新
- **解码线程**：由 PlayerController 管理，从文件读取并解码 PCM 数据，写入环形缓冲区
- **SDL 音频回调线程**：由 SDL2 内部管理，从环形缓冲区读取 PCM 数据输出到设备

解码线程与 SDL 回调线程通过环形缓冲区的互斥锁实现线程安全。

## 六、构建与依赖

**构建工具**：CMake

**第三方依赖**：
- Qt6（Core、Qml、Quick 模块）
- SDL2
- FFmpeg 库（libavcodec、libavformat、libavutil、libswresample）

**QML 注册方式**：C++ 类通过 qmlRegisterType 注册到 QML 引擎，QML 中通过 import 语句使用。

## 七、QML UI 组成

| 组件 | 职责 |
|------|------|

| PlayerControls.qml | 播放/暂停、上一首/下一首、进度条、音量控制、时间显示

## 九、注意事项

1. **线程安全**：SDL 音频回调在独立线程中运行，所有数据访问需加锁或使用无锁队列。
2. **文件格式**：FFmpeg 支持 mp3/flac/wav/aac/ogg/ape/wv 等，需确保系统安装了对应解码器。
3. **seek 精确度**：FFmpeg 对压缩格式的 seek 不一定精确到帧边界。
4. **内存管理**：FFmpeg 对象需严格配对释放，防止内存泄漏。
5. **SDL 初始化**：需在 Qt 事件循环启动前调用 SDL_Init，在程序退出时调用 SDL_Quit。
6. **音量控制**：SDL2 不直接提供音量 API，在回调中对 PCM 采样值乘系数实现。
