# 音乐播放器开发文档

## 技术栈

- Qt6 + QML 界面
- FFmpeg 解码音频
- SDL2 输出声音
- CMake 构建，C++17

## 整体结构

QML界面→ PlayerController → 音频处理

数据流：文件 → FFmpeg解码 → 重采样(44100Hz/双声道/float32) → RingBuffer → SDL2 → 声卡

## C++ 模块

### AudioDecoder

FFmpeg 解码器。打开音频文件，解码成统一格式的 PCM。支持读取、seek、提取封面。

### SDLAudioOutput

SDL2 音频输出。从 RingBuffer 读数据往声卡送，音量控制在回调里手动乘系数。

### RingBuffer

环形缓冲区，解码线程写、SDL 回调读。满了就等，空了也等。切歌时清空。

### SpeedSwitch

变速不变调。用 FFmpeg 的 atempo 滤镜，范围 0.5~2.0 倍速。超过 2.0 时串联多个滤镜。

### PlayerController

核心模块，把上面这些串起来。管理播放状态（暂停、进度、音量、切歌），通过 Q_PROPERTY 暴露给 QML。启动解码线程，播放完自动切歌。

### CoverImageProvider

封面图片提供器。QML 通过 `image://cover/current` 拿封面，切换歌曲时更新，不用临时文件。

### LyricsParser

歌词解析。支持 LRC（逐行）和 YRC（逐字）两种格式。LRC 整行高亮，YRC 逐字高亮。

### LyricsFetcher

歌词获取。从网易云 API 搜歌词，异步请求，搜到了发信号通知。

### PlaylistModel

播放列表数据模型。存当前播放队列，支持增删、判断是否包含、切换播放模式（循环/单曲/随机）。

### PlaylistManager

歌单管理。管多个命名歌单，支持新建、删除、重命名、增删歌曲。数据存 JSON 文件。

### SongSearcher

在线搜索。调用网易云 API 搜歌曲，过滤能播放的，下载到本地缓存目录。

### SearchResultModel

搜索结果数据模型，给 QML 的 ListView 用。

## 线程

| 线程 | 职责 |
| 主线程 | Qt 事件循环，UI + 状态更新 |
| 解码线程 | 循环解码写 RingBuffer |
| SDL 回调线程 | 从 RingBuffer 读数据输出 |

同步：RingBuffer 用锁+条件变量，标志位用原子变量，解码线程到主线程用信号槽。

## QML 文件

| 文件 | 作用 |
| Main.qml | 主窗口，管理全局状态和页面切换 |
| ControlBar.qml | 底部控制栏：播放、切歌、进度条、音量、变速 |
| PlaylistSidebar.qml | 播放列表侧边栏，从右侧滑出 |
| SearchPage.qml | 搜索在线歌曲 |
| PlaylistsPage.qml | 我的歌单列表 |
| PlaylistDetailPage.qml | 歌单详情，歌曲列表 |
| LyricsPage.qml | 歌词页，逐字高亮 |

## 实现的功能

### 播放控制

| 功能 | 说明 |
| 播放/暂停 | 点击按钮切换播放状态 |
| 停止 | 停止当前播放 |
| 上一首/下一首 | 切换歌曲 |
| 进度跳转 | 拖动进度条 seek 到指定位置 |
| 自动切歌 | 播放完毕根据模式自动切换下一首 |

### 音频特性

| 功能 | 说明 |
| 格式支持 | mp3、flac、wav、aac、ogg、ape |
| 变速播放 | 0.5x~2.0x 倍速，不变调 |
| 音量调节 | 滑块控制音量大小 |
| 静音 | 一键静音/恢复 |

### 播放模式

| 模式 | 说明 |
| 列表循环 | 播完从头开始 |
| 单曲循环 | 重复播放当前歌曲 |
| 随机播放 | 随机选下一首 |

### 歌曲管理

| 功能 | 说明 |
| 本地添加 | 选择本地音频文件添加到播放列表 |
| 在线搜索 | 搜索网易云音乐歌曲 |
| 在线播放 | 搜索后直接播放在线歌曲 |
| 缓存下载 | 在线歌曲下载到本地缓存 |
| 队列管理 | 播放列表增删、清空 |

### 歌单功能

| 功能 | 说明 |
| 新建歌单 | 创建命名歌单 |
| 删除歌单 | 删除整个歌单 |
| 重命名 | 修改歌单名称 |
| 添加歌曲 | 向歌单内添加歌曲 |
| 移除歌曲 | 从歌单内移除歌曲 |
| 数据持久化 | 歌单数据存 JSON 文件 |

### 歌词显示

| 功能 | 说明 |
| 本地歌词 | 加载同目录下 .lrc/.yrc 文件 |
| 在线歌词 | 从网易云 API 获取歌词 |
| 逐字高亮 | YRC 格式每个字单独高亮 |
| 逐行高亮 | LRC 格式整行高亮 |
| 点击跳转 | 点击歌词行跳转到对应时间 |
