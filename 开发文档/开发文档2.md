# 音乐播放器开发文档

## 技术栈

- **UI**：Qt6 + QML，声明式界面，前后端分离
- **音频解码**：FFmpeg，支持 mp3/flac/wav/aac/ogg/ape
- **音频输出**：SDL2，跨平台低延迟
- **构建**：CMake，C++17
- **后端**：C++ 类通过 QML_ELEMENT 注册到 QML

## 架构

从顶到底三层：

1. **QML 层** — 页面和组件，管界面交互
2. **C++ 层** — PlayerController 做桥接，串起各个模块
3. **音频处理层** — FFmpeg 解码成 PCM，SDL2 输出

数据流：`文件 → FFmpeg 解封装 → 解码 → 重采样 → 环形缓冲区 → SDL2 回调 → 扬声器`

## 各模块功能

### AudioDecoder

用 FFmpeg 打开音频文件，解码成统一格式的 PCM（44100Hz、双声道、float32）。
提供打开/关闭/读取 PCM/seek 等接口，内部维护解码器状态。

### SDLAudioOutput

初始化 SDL 音频设备，设好回调函数。回调从环形缓冲区取数据往声卡塞。
暂停/恢复对应 SDL_PauseAudioDevice。
音量回调里手动乘系数，SDL 没直接提供音量 API。

### PlayerController

注册成 QML 类型，所有播放状态通过 Q_PROPERTY 暴露：playing、duration、position、volume、speed、muted、currentTitle、playMode 等。
启动解码线程循环读 PCM 塞缓冲区，SDL 回调另一边消费。
进度用定时器轮询。
播完后自动切歌，支持列表循环、单曲循环、随机三种模式。

### RingBuffer

固定大小的环形队列，用 mutex + condition_variable 做同步。
解码线程写、SDL 回调读，满了或空了就等待。
seek 或切歌时清空。

### LyricsParser

解析 LRC（逐行）和 YRC（逐字）两种歌词格式。
YRC 用于逐字高亮，每行里每个字都有时间偏移。
提供 textAt(time) 查当前行，progressAt(time) 算高亮进度。

### LyricsFetcher

从网易云音乐 API 搜歌词，异步请求，回来后发信号通知。

### PlaylistModel / PlaylistManager

PlaylistModel 是当前播放列表的数据模型。
PlaylistManager 管多个命名播放列表，支持新建/删除/重命名/增删歌曲。
实现歌单持久化

### SpeedSwitch

用 FFmpeg 的 atempo 滤镜做变速不变调。
解码后的 PCM 过一遍滤镜再进缓冲区。
范围 0.5~2.0。

## 线程

一共三条线程：

- **主线程**（Qt 事件循环）：UI + Controller 状态更新
- **解码线程**：解码文件写 RingBuffer，原子变量控制退出
- **SDL 回调线程**：从 RingBuffer 读数据输出

同步手段：RingBuffer 用锁 + 条件变量，控制标志用原子变量，解码到主线程的通信用信号槽。

## QML 页面

| 区域 | 功能|
|------|------|
| 底部控制栏 | 暂停/播放、切歌、进度条、音量、变速、播放模式 |
| 播放队列 | 当前歌曲列表，双击播放，右键菜单 |
| 我的歌单 | 用户创建的歌单入口，点进去看详情 |
| 歌单详情 | 歌单里的歌曲列表 |
| 歌词页 | 滚动歌词，逐字高亮 |

## 歌词显示

先加载本地同目录下的 .lrc/.yrc，没有再联网从网易云拉。
有 YRC 就逐字高亮，没有就用 LRC 整行高亮。
每 50ms 更新一次当前行和高亮进度。
