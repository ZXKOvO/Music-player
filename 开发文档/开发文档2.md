# 音乐播放器开发文档

## 技术栈

- Qt6.9 + QML 界面
- FFmpeg 解码音频（libavcodec、libavformat、libavutil、libswresample、libavfilter）
- SDL2 输出声音
- CMake 构建，C++17

## 整体结构

QML界面 → PlayerController → 音频处理

数据流：文件 → FFmpeg解码 → 重采样(44100Hz/双声道/float32) → SpeedSwitch(atempo变速) → RingBuffer → SDL2 → 声卡

## C++ 模块

### AudioDecoder

FFmpeg 解码器。打开音频文件，解码成统一格式的 PCM。支持读取、seek、提取封面。

### SDLAudioOutput

SDL2 音频输出。从 RingBuffer 读数据往声卡送，音量控制在回调里手动乘系数。

### RingBuffer

环形缓冲区，解码线程写、SDL 回调读。满了就等，空了也等。切歌时清空。

### SpeedSwitch

变速不变调。用 FFmpeg 的 atempo 滤镜，范围 0.5~2.0 倍速。超过 2.0 时串联多个滤镜。

### PlayerController

核心模块，把上面这些串起来。管理播放状态（暂停、进度、音量、切歌），通过 Q_PROPERTY 暴露给 QML。启动解码线程，播放完自动切歌。

### CoverImageProvider

封面图片提供器。QML 通过 `image://cover/circle` 拿圆形裁剪封面，`image://cover/file/<路径>` 拿指定文件的封面。支持内存缓存，切换歌曲时更新，不用临时文件。

### NetImageProvider

网络图片提供器。QML 通过 `image://net/<歌曲ID>` 获取在线歌曲专辑封面。单例模式，支持原始字节和解码图像双缓存。

### LyricsParser

歌词解析。支持 LRC（逐行）和 YRC（逐字）两种格式，自动检测。LRC 和 YRC 均生成逐字高亮时间信息，供 QML 逐字渲染。

### LyricsFetcher

歌词获取。从网易云 API 搜歌词，异步请求，搜到了发信号通知。优先请求 YRC 逐字歌词，找不到再请求 LRC 逐行歌词。

### PlaylistModel

播放列表数据模型。存当前播放队列，支持增删、判断是否包含、切换播放模式（循环/单曲/随机）。

### PlaylistManager

歌单管理。管多个命名歌单，支持新建、删除、重命名、增删歌曲、拖拽排序。数据存 JSON 文件。

### SongSearcher

在线搜索。调用网易云 API 搜歌曲，过滤能播放的，下载到本地缓存目录。同时下载专辑封面。

### SearchResultModel

搜索结果数据模型，给 QML 的 ListView 用。提供歌曲 ID、名称、艺术家、专辑、时长等角色。

## 线程

| 线程 | 职责 |
| 主线程 | Qt 事件循环，UI + 状态更新 |
| 解码线程 | 循环解码写 RingBuffer，SpeedSwitch 变速处理 |
| SDL 回调线程 | 从 RingBuffer 读数据输出 |

同步：RingBuffer 用锁+条件变量，标志位用原子变量，解码线程到主线程用信号槽。

## QML 文件

| 文件 | 作用 |
| Main.qml | 主窗口，管理全局状态、页面切换、桌面歌词窗口 |
| ControlBar.qml | 底部控制栏：播放、切歌、进度条、音量、变速、封面 |
| PlaylistSidebar.qml | 播放列表侧边栏，从右侧滑出，支持悬停自动打开 |
| SearchPage.qml | 搜索在线歌曲 |
| PlaylistsPage.qml | 我的歌单列表 |
| PlaylistDetailPage.qml | 歌单详情，歌曲列表，支持拖拽排序 |
| LyricsPage.qml | 歌词页，逐字高亮，可调字号，点击跳转 |
| ConfirmDialog.qml | 通用确认对话框组件 |

## 实现的功能

### 播放控制

| 功能 | 说明 |
| 播放/暂停 | 点击按钮切换播放状态 |
| 停止 | 停止当前播放，重置状态 |
| 上一首/下一首 | 根据播放模式切换歌曲 |
| 进度跳转 | 拖动进度条 seek 到指定位置（150ms 防抖） |
| 自动切歌 | 播放完毕根据模式自动切换下一首 |

### 音频特性

| 功能 | 说明 |
| 格式支持 | mp3、flac、wav、aac、ogg、ape |
| 变速播放 | 0.5x~2.0x 倍速，不变调，步长 0.1 |
| 音量调节 | 滑块控制音量大小 |
| 静音 | 一键静音/恢复 |

### 播放模式

| 模式 | 说明 |
| 列表循环 | 播完从头开始 |
| 单曲循环 | 重复播放当前歌曲 |
| 随机播放 | 随机选下一首（上一首也随机） |

### 歌曲管理

| 功能 | 说明 |
| 本地添加 | 选择本地音频文件添加到播放列表（支持多选） |
| 在线搜索 | 搜索网易云音乐歌曲 |
| 在线播放 | 搜索后直接播放在线歌曲 |
| 缓存下载 | 在线歌曲下载到本地缓存目录 |
| 队列管理 | 播放列表增删、清空 |
| 重复检测 | 添加歌曲时自动检测重复 |
| 歌曲时长 | 添加时自动提取音频时长 |

### 歌单功能

| 功能 | 说明 |
| 新建歌单 | 创建命名歌单 |
| 删除歌单 | 删除整个歌单（二次确认） |
| 重命名 | 修改歌单名称 |
| 添加歌曲 | 向歌单内添加歌曲（从队列选择或文件导入） |
| 移除歌曲 | 从歌单内移除歌曲（二次确认） |
| 拖拽排序 | 长按 600ms 拖拽调整歌曲顺序 |
| 编辑歌曲名 | 仅修改歌单内显示标题，不修改音频文件 |
| 数据持久化 | 歌单数据存 JSON 文件 |
| 在线缓存迁移 | 在线下载的歌曲自动复制到永久存储 |

### 歌词显示

| 功能 | 说明 |
| 本地歌词 | 加载同目录下同名 .lrc/.yrc 文件 |
| 在线歌词 | 从网易云 API 获取歌词 |
| 逐字高亮 | YRC 格式每个字单独高亮 |
| 逐行高亮 | LRC 格式整行高亮（内部转为逐字时间） |
| 点击跳转 | 点击歌词行跳转到对应时间 |
| 字号调节 | 12~36 可调，持久化保存 |
| 桌面歌词 | 悬浮歌词窗口，置顶显示，可拖动 |
| 桌面歌词进度条 | 桌面歌词窗口内可拖动进度条，与主窗口同步 |
| 桌面歌词颜色 | 7 种颜色可选（绿、青、黄、橙、粉、紫、白） |
| 桌面歌词控制 | 上一首/播放暂停/下一首按钮 |

### 封面显示

| 功能 | 说明 |
| 内嵌封面 | 从音频文件提取封面（附件流/视频流/元数据） |
| 圆形封面 | 控制栏显示圆形裁剪封面，播放时旋转 |
| 歌词背景 | 歌词页使用封面作为背景（半透明遮罩） |
| 歌单缩略图 | 歌单列表显示第一首歌曲的封面缩略图 |
| 在线封面 | 在线歌曲自动下载专辑封面 |

### 界面功能

| 功能 | 说明 |
| 控制栏 | 底部播放控制、进度条、音量、变速 |
| 侧边栏 | 播放列表侧边栏，从右侧滑出，悬停自动打开 |
| 搜索页 | 在线歌曲搜索界面，显示封面/歌名/艺术家 |
| 歌单页 | 歌单列表和详情页面 |
| 左侧面板 | 可折叠的搜索/歌单切换面板 |
| 全屏模式 | 双击控制栏进入全屏，布局自适应放大 |
| 提示 | 操作反馈 Toast 提示消息（2 秒自动消失） |

### 设置持久化

| 功能 | 说明 |
| 音量保存 | 记住上次音量设置 |
| 歌词字号 | 记住歌词页面字号设置 |
