# Qt 本地音乐播放器 - 开发文档

## 1. 项目概述

### 1.1 项目名称

Qt Local Music Player

### 1.2 项目目标

基于 Qt 框架开发一款本地音乐播放器，支持常见音频格式的播放与管理，提供简洁直观的用户界面。

### 1.3 技术栈

| 类别 | 选型 |
|------|------|
| 语言 | C++23 / QML (ECMAScript) |
| UI 框架 | Qt 6 Quick (QML) |
| 音频引擎 | QMediaPlayer / QAudioOutput |
| 构建系统 | CMake 4.1+ |
| 数据库 | SQLite (播放列表持久化) |
| 元数据 | TagLib |

### 1.4 支持平台

- Linux

## 3. 系统架构

### 3.1 分层职责

- **UI Layer (QML)**: Qt Quick 界面，使用 QML 声明式语法构建 UI，通过属性绑定与 C++ 后端交互，不包含业务逻辑
- **Controller Layer (C++)**: 暴露给 QML 的后端控制器，使用 Q_PROPERTY / Q_INVOKABLE 供 QML 调用，协调各 Service
- **Service Layer (C++)**: 核心业务逻辑，可独立于 UI 运行，不依赖 QML 类型
- **Data Layer (C++)**: 底层依赖，包括 Qt Multimedia、SQLite、TagLib
