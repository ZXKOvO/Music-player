# Music Player

一个功能丰富的桌面音乐播放器，基于 Qt6 + FFmpeg + SDL2 技术栈开发。支持本地和在线音乐播放，提供逐字歌词显示、桌面歌词、歌单管理等功能。

## 功能特性

### 播放控制
- 播放/暂停/停止
- 上一首/下一首
- 进度跳转（150ms 防抖）
- 自动切歌

### 音频特性
- 格式支持：mp3、flac、wav、aac、ogg、ape
- 变速播放：0.5x~2.0x（步长 0.1），不变调
- 音量调节与静音
- 统一输出格式：44100Hz/双声道/float32

### 播放模式
- 列表循环
- 单曲循环
- 随机播放

### 歌曲管理
- 本地文件添加（支持多选）
- 在线搜索与播放（网易云音乐）
- 播放队列管理（增删清空）
- 歌曲重复检测
- 自动提取歌曲时长

### 歌单功能
- 创建/删除/重命名歌单
- 添加/移除歌曲
- 拖拽排序（长按 600ms）
- 编辑歌曲显示名称
- JSON 数据持久化
- 在线缓存自动迁移

### 歌词显示
- 本地歌词加载（LRC/YRC 格式）
- 在线歌词获取（网易云 API）
- 逐字高亮显示
- 字号调节（12~36）
- 桌面歌词悬浮窗口
- 桌面歌词颜色选择（7 种颜色）
- 桌面歌词进度条与控制按钮

### 封面显示
- 内嵌封面提取（附件流/视频流/元数据）
- 圆形旋转封面（控制栏）
- 歌词背景封面
- 歌单缩略图
- 在线封面下载

### 界面功能
- 可折叠左侧面板
- 播放列表侧边栏（悬停自动打开）
- 全屏模式（双击控制栏）
- Toast 提示消息

## 架构概览

### 技术栈
- 语言：C++17
- UI 框架：Qt 6.9+ (Qt Quick / QML)
- 音频解码：FFmpeg (libavcodec, libavformat, libavutil, libswresample, libavfilter)
- 音频输出：SDL2
- 构建系统：CMake 3.16+

### 数据流
文件 → FFmpeg解码 → 重采样(44100Hz/双声道/float32) → SpeedSwitch(atempo变速) → RingBuffer → SDL2 → 声卡

### 线程模型
| 线程 | 职责 |
|------|------|
| 主线程 | Qt 事件循环，UI 更新，状态管理 |
| 解码线程 | 循环解码写 RingBuffer，SpeedSwitch 变速处理 |
| SDL 回调线程 | 从 RingBuffer 读数据输出到声卡 |

## 依赖
- Qt 6.9+
- FFmpeg（libavcodec、libavformat、libavutil、libswresample、libavfilter）
- SDL2
- CMake 3.16+
- C++17

## 使用
1. 点击底部"+"按钮添加本地音频文件
2. 在搜索页搜索在线歌曲
3. 双击歌曲播放
4. 在"我的歌单"页管理歌单
5. 点击歌词按钮开启桌面歌词
6. 双击控制栏进入全屏模式
7. 从右侧边缘悬停打开播放列表侧边栏
